#Sharaf DG Automation Test Suite
#Automation framework for Login, Registration, and Checkout flows on Sharaf DG staging, built with Java, Selenium WebDriver, and TestNG, following the Page Object Model (POM) design pattern.
---

## 🧰 Tech Stack

- **Language: Java 24.0.1 (OpenJDK)
- **Testing: TestNG, Selenium WebDriver
- **Build: Maven with Surefire Plugin
- **Design: Page Object Model (POM)
- **Data Handling: JSON (Jackson), Lombok
- **Browsers: Chrome, Safari (parameterized via TestNG)

---

## ✅ Features

Modular POM structure for maintainability
Comprehensive tests for login, registration, and product checkout
JSON-driven test data using TestNG DataProvider
Cross-browser support with easy parameterization
Maven Surefire generates detailed HTML test reports

---

## 📁 Framework Structure

```
sharaf-dg-automation/
├── src/main/java/com/sharafdg/
│   ├── base/              # Test base and WebDriver setup
│   ├── dao/               # POJOs for JSON test data (LoginDao, RegistrationDao)
│   ├── dataprovider/      # DataProvider implementations  
│   ├── driver/            # Driver factory for browser initialization  
│   ├── page/              # Page classes for different screens  
│   └── util/              # Utility classes (JSON reading, helpers)

```

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/gupta2010anshul/sharaf-dg-automation.git
cd sharaf-dg-automation
```

### 2. Install dependencies
```bash
mvn clean install -DskipTests
```

### 3. Run the tests using Maven Surefire and TestNG parameters

**For Chrome**:
```bash
mvn test -Dbrowser=chrome -Durl=https://uae.sdgstage.com
```

**For Safari**:
```bash
mvn test -Dbrowser=safari -Durl=https://uae.sdgstage.com
```

> These parameters are injected into TestNG via Maven Surefire Plugin configured in `pom.xml`.
